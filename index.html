MIXER — per-bus filter / volume / step automation

Each pad routes to a bus (Drums / Bass / Melody / FX / Perc). Every bus has its own low-pass filter, fader and a 16-step automation lane for both — draw a curve and it plays back locked to the sequencer, the way Koala's step automation works but across every bus instead of one channel at a time. Samples aren't saved into the project file (browser storage limits) — saving stores pad/bus/pattern/mixer state so you can reload the same kit fast.
